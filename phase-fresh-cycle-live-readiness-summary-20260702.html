What Changed

  • Added a closed-cycle CEO review action so completed boards are not inert after exports are delivered.
  • Stamped fresh-cycle runs with runtimeContext.previousRunId for safe predecessor lineage.
  • Replaced the stale unique tenant/workflow run index with a latest-run lookup index.
  • Added a partial unique successor index so one completed run cannot spawn multiple successor cycles.
  • Updated migration helper verification so stage/live setup fails closed if the new schema shape is missing.
  • Preserved previousRunId through Postgres runtime-context mapping without allowing secret values through.
