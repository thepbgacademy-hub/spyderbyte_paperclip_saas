Durable Operator Controls

This phase wired the first real operator control lane into the runtime without widening into job admin, secret rotation, run cancellation, or Paperclip-disable semantics.

Implemented

Runtime Wiring

The runtime now mounts a default operator HTTP handler backed by Postgres dependencies unless a test handler is injected.

  • Durable operator lookup uses wfpc.tenant_memberships.
  • Tenant pause/resume uses wfpc.tenants.paused_at.
  • The session tenant remains authoritative over URL/body tenant input.
Guardrails

Scope Fence

Deferred operator surfaces are explicit instead of silently pretending to work.

  • Unsupported commands return 501 operator_operation_not_implemented.
  • Pause and emergency disable require a reason capped at 500 characters.
  • Owner/admin/operator durable memberships can authorize through the service check.
